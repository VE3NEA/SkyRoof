## SkyRoof Components

These libraries are developed as part of the SkyRoof project and are maintained in their own
repositories:

- [VE3NEA.SkySignals](https://github.com/VE3NEA/VE3NEA.SkySignals) — the `VE3NEA.Dsp`,
  `VE3NEA.SkyTlm`, `VE3NEA.SkySSTV` and `VE3NEA.SkyFM` libraries
- [ft4_coder](https://github.com/VE3NEA/ft4_coder) — `ft4_coder.dll` is built from
  [WSJT-X](https://wsjt.sourceforge.io/wsjtx.html) sources, and the FT4 encoding and decoding it
  performs is the work of the WSJT-X developers

## Separately Installed Components

These are not included in the SkyRoof setup program. Users who enable FM speech decoding download
and install them by hand:

- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)
- [ONNX Runtime](https://onnxruntime.ai/)
